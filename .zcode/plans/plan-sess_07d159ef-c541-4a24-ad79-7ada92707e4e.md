# Take Five 全面深度优化

已复核全部代码（electron/ 4 文件 1336 行 + app/ 全部页面 + hooks + types），确认约 30 个具体问题。分四层实施，最后统一验证。

## 一、正确性修复（真 bug）

1. **隔夜边界失效 + 次日首专注被误清空**（`electron/timer.mjs`，最严重）：`checkWorkBoundary` 只在 250ms tick 里跑，而 idle/paused/break-prompt 时 interval 已停 → 整夜挂托盘后上班 autostart 不触发；且 `lastInWorkHours` 停留在昨晚的 false，次日手动点「开始专注」后首次 tick 会走 `enterWorkday → endWorkday` 把刚开的会话清掉。修法：新增常驻 30s 看门狗 interval 只跑 `checkWorkBoundary`（幂等，可与 tick 并存）；`enterWorkday` 移除「非 idle 就 endWorkday」，只处理 idle 下的 autostart；`startFocus` 同步 `lastInWorkHours`。
2. **`soundEnabled` 连通知一起关掉**（`electron/main.mjs:265`）：改为 `silent: !soundEnabled`，关的只是提示音。
3. **maxPostpones / strictMode 主进程不设防**（`timer.mjs` postponeBreak）：`state.maxPostpones` 写了 4 处从未读取，约束只在渲染层，preload 可无限推迟。修法：postponeBreak 里 strictMode 直接拒绝、`postponeCount >= maxPostpones` 拒绝；UI 侧达到上限时禁用推迟按钮。
4. **安静时段自动顺延虚增统计**（`timer.mjs:164-188`）：每次自动顺延都写一条 `postponed` 事件，「今日推迟」被用户没做过的操作灌满。修法：不写事件、不增 `postponeCount`，只保留顺延逻辑与 `afterPostpone` 标记。
5. **休息时长记账失真**（`timer.mjs:346-348`）：自然结束按配置的 `breakMinutes*60` 而非实际 `elapsedMs` 记账，休息中途改设置即不一致。统一用 `elapsedMs`。
6. **startFocus 残留旧推荐活动**（`timer.mjs:253-275`）：补重置 `suggestedActivity`/`checkedActivities`。
7. **周统计日期标签错一天**（`electron/db.mjs:349`）：本地零点经 `toISOString()` 在 UTC+8 变前一天。改本地日期格式化。
8. **streak 静默 60 天截断**（`db.mjs:295`）：随统计合并查询重做。
9. **settings/stats 页 hydration mismatch**（`app/settings/page.tsx:32`、`app/stats/page.tsx:32`）：静态导出 HTML 与运行时首帧分支不同（`hasDesktopApi()` SSR 为 false）。对齐 Home 的 `ready` 门。
10. **主题双写 + 双真源**（`settings/page.tsx:84-87`、`theme-provider.tsx`）：一次点击两笔 IPC 两笔落库。收敛为 setTheme 单点持久化；同时修 theme-provider 在 state updater 里跑 DOM 副作用（StrictMode 双调用）与 matchMedia 三处重复创建。
11. **nav 反模式 + hide-nav 依赖缺失**（`components/nav.tsx`、`nav-active.tsx`）：改 nav 为 client 组件用 `usePathname` 算 active；hide-nav 补查询参数依赖（layout 包 Suspense）；break 窗隐藏 nav 改为脱离 tab 序（display:none）。

## 二、性能

12. **settings 热路径每秒约 8 次全表读**（`db.mjs:95` ← `timer.mjs:74,231`）：getSettings 加模块级缓存，setSettings 失效。一行消除最大 DB 开销。
13. **统计 N+1**（`db.mjs:296-347`，被 useStats 15s 轮询放大）：一条 `GROUP BY date(..., 'localtime')` 查询同时产出今日三格、streak、周图；补 `scheduled_at`/`resolved_at` 索引。
14. **useStats 盲轮询**（`lib/hooks.ts:106-110`）：`document.hidden` 跳过 + visibilitychange 立即刷新。
15. **250ms 全树重渲染**（`app/page.tsx`）：BreakOverlay 删掉仅为取 `call` 的二次 `useTimerState()`（改 props 传入）；`ProgressRing`/`ActivityChips` memo 化；移除永不完成的 280ms stroke-dashoffset transition（与 250ms tick 打架，纯 GPU 浪费）。
16. **托盘 tooltip 每 250ms 刷**（`main.mjs:165-171,282`）：字符串去重，内容不变不更新。

## 三、健壮性

17. **静态服务器加固**（`main.mjs:74-91`）：`startsWith` 裸前缀可被 `out-secret/` 等兄弟目录穿越 → 改 `path.relative` 边界判断；SPA fallback 收窄（带扩展名的 404 直接 404，别把 HTML 当 JS 发）；`before-quit` 补 `server.close()`。
18. **单实例锁**（`main.mjs`）：`requestSingleInstanceLock` + `second-instance` 聚焦主窗，避免双托盘/双计时器/同 DB 双写。
19. **启动失败静默白屏**（`main.mjs:418-428`）：`openDb()` 与 `resolveAppBase()` 失败目前只 console.error（打包后不可见，窗口永不显示）→ `dialog.showErrorBox` 兜底。
20. **IPC 输入校验**（`main.mjs:341-349`）：`settings:set` 按 DEFAULTS 白名单 + 类型钳制（数字范围、布尔、`HH:MM` 格式、activities 合法 id）；`stats:events` limit clamp。
21. **DB 层**：移除会改写用户合法配置的 quietHoursStart 迁移启发式（`db.mjs:76-81`）；setSettings 事务化；openDb 加容错报错。
22. **进程加固**：两个窗口 `sandbox: true`（preload 只用 electron API）；托盘图标由裸 RGB 位图（Windows 上 BGRA 通道序会变橙红色）改为内嵌 PNG buffer。
23. **hooks 统一错误处理**（`lib/hooks.ts`）：useSettings/useStats/call 补 try/catch + error 态，页面可重试，不再永久卡「加载中」。

## 四、UI/UX 与清理

24. **设置输入防抖**（`settings/page.tsx`）：数字/时间改受控草稿 + blur/防抖提交 + clamp，不再逐键写库、清空跳回默认值。
25. **a11y**：倒计时 `aria-live="polite"` 改 `role="timer"`（不再每秒播报）；BreakOverlay 补焦点陷阱 + 自动聚焦主按钮。
26. **主题首帧闪变**：layout head 加内联 pre-paint 脚本（localStorage 镜像 + prefers-color-scheme）先于渲染设 `data-theme`。
27. **活动清单单源化**：新建 `lib/activities.ts`（id+label），settings 页、stats 页、`ActivityIcon` 共用；if 链改 Record 映射；删 `TimerState.activityCopy` 死字段。
28. **死代码清理**：`db.updateBreakEvent`、`timer.setCheckedActivities`、preload/types 的 `onBreakDue` 死通道、`selectable={isBreak || isBreakView}` 死表达式、CSS 死规则（`.is-break-prompt`、`.icon-btn.is-on`、72px time-display、`.field select`）。
29. **CSS token 收敛**（`globals.css`）：约 15 处硬编码灰色 rgba 收敛为 `--surface`/`--border` token；`--text-faint` 对比度提到 ≥4.5:1（DESIGN.md 自定标准）；work/quiet banner 样式合并；环尺寸三处真源合一到 ProgressRing。
30. **DESIGN.md 同步**：accent 实际是绿色、字阶缺 48px、"双环"未实现等漂移按实现回写。
